# DevBlog

A blog application built with Python and Django for publishing and managing IT-related content.

## 🛠️ Technologies

* Python
* Django
* SQLite
* HTML
* CSS

## ✨ Features

* Blog posts
* Post management
* Django templates
* Database integration
* Web-based interface

## 🎯 Project Goal

DevBlog is a practical Django project created to improve backend development skills and experience with building web applications.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/AbiwDev/DevBlog.git
cd DevBlog
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

### 3. Activate the virtual environment

Windows:

```bash
.venv\Scripts\activate
```

### 4. Install Django

```bash
pip install django
```

### 5. Apply migrations

```bash
python manage.py migrate
```

### 6. Run the server

```bash
python manage.py runserver
```

The application will be available at:

```text
http://127.0.0.1:8000/
```
